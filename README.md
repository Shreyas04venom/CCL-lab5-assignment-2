## 🎯 Objective

The main objectives of this assignment are:

- To create and configure an **Amazon EC2 instance**.
- To configure the required network and security settings.
- To work with **Amazon DynamoDB**.
- To understand cloud-based NoSQL database operations.
- To connect and interact with AWS services.
- To verify the successful execution of the required operations.

---

## ☁️ AWS Services Used

The following AWS services are used in this assignment:

### 1. Amazon EC2

Amazon EC2 provides the virtual server used for performing the required cloud computing operations.

### 2. Amazon DynamoDB

Amazon DynamoDB is a fully managed NoSQL database service used for storing and retrieving application data.
